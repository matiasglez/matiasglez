## Proyecto destacado

### Volt - API REST de e-commerce
> Django REST Framework - PostgreSQL - Docker

API REST de e-commerce que resuelve los dos problemas que suelen romper un checkout online: que dos
compras simultáneas se lleven el mismo stock y que un webhook de pago llegue duplicado o manipulado.

Incluye autenticación JWT, catálogo, carrito, pedidos y confirmación de pagos con Mercado Pago.
Está desplegada en producción con datos de demo para recorrer el flujo completo.

- 26 endpoints REST documentados con OpenAPI 3.0 y Swagger UI en vivo
- Checkout transaccional con `select_for_update` (control de concurrencia sobre el stock)
- Webhook de Mercado Pago idempotente con verificación de firma HMAC-SHA256
- 78 tests con **DRF APITestCase** ejecutados en CI sobre **Docker** (GitHub Actions)
- Despliegue en Render con PostgreSQL y Gunicorn

[Repositorio](https://github.com/matiasglez/ecommerce-backend) | [Demo en vivo](https://volt-store-plum.vercel.app) | [Documentación de la API](https://volt-matiasglez-ecommerce.onrender.com/api/schema/swagger-ui/)
